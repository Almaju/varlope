Every crate a component depends on is vendored into mozilla-central and must be vetted there, so dependency changes need care beyond `cargo build`: `workspace = true` inheritance broke vendoring once (#5352), test and CLI crates (`env_logger`, `mockall`, `clap`) in a component's `[dependencies]` become shipping code m-c has to audit, and a `cargo audit --ignore` without a reason outlives the problem it hid. The m-c version and cargo-vet checks need mozilla-central's lockfile and audits, so they stay a review item.
