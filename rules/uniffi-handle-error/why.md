Components keep an internal `Error` and expose a smaller public `ApiError`; `#[handle_error(Error)]` does the conversion through `GetErrorHandling`, which is also where unexpected errors get logged and reported to Glean/Sentry. An exported function that stringifies an error into the public type by hand, or an `impl From<..> for XApiError`, skips that step, so the failure is never reported ("I'd rather if everything always went through the `get_error_handling` method above").
