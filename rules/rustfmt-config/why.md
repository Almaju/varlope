Reviewers spend comments on what a formatter should decide: import order and grouping (std, external crates, then `crate::`), nested `use a::{b::{c, d}}` trees, imports added halfway down a file ("Nit: move the imports to the top"), and `use foo::*` that pulls a whole module into scope. Configuring rustfmt (`group_imports`, `imports_granularity`) and running it in CI ends those threads for good.
