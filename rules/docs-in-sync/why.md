Comments and docs go stale silently when code moves: a doc link to a method that was renamed, a comment pointing at a file that no longer exists ("you probably copied this, but I think that file no longer exists"), a README linking a directory that was renamed. CI doesn't run rustdoc with `broken_intra_doc_links`, so nothing catches them; varlope checks `Self::`/`crate::` links and repo paths, while stale prose stays a review item.
