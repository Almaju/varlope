`DEPENDENCIES.md`, `dependency-licenses.xml`, `Cargo.lock` and `Package.resolved` are written by tools, so a diff in them should come from the change that caused it: a hand edit to a license summary is undone by the next regeneration, a stray `cargo update` hides real dependency changes in a feature PR, and Xcode rewrites `Package.resolved` when you switch branches. Reviewers repeatedly had to ask "did you run `cargo update`?" or "is this change intended?".
