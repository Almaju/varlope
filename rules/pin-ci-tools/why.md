A floating image tag, an unpinned `pip`/`cargo`/`gem install` or a deprecated action version changes CI without anyone committing anything: an unpinned swiftformat upgrade started failing code that had passed (#5783), `upload-artifact@v3` stopped working when GitHub retired it (#6630), and workflows that installed rustup without `rustup toolchain install` built with the wrong toolchain (#6632). Pin the version and let Dependabot propose bumps as reviewable PRs.
