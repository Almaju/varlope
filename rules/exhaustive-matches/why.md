Code that handles "every variant" or "every field" by hand silently goes stale when one is added: a new search-config field was never propagated by `SearchEngineUrl::merge` (#6866), and ads-client's request hash left out fields that distinguish requests until review caught it (#7315, #7368). Naming every variant in a `match`, and destructuring without `..` in merges, turns the next addition into a compile error ("I really like how this doesn't have a default branch").
