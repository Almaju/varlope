Kotlin, Swift and JS code compiles against the generated bindings, so removing or renaming an exported item, changing a signature, or adding a record field or argument without a UniFFI default breaks Firefox for Android, iOS or Desktop the next time they update (#4975: `SyncUnlockInfo` gained a required `tabsLocalId` and broke firefox-ios). Reviewers keep asking for such changes to be listed under Breaking Changes in CHANGELOG.md, so the consumer patches are ready before the release.
