Reviewers' most frequent request is "why this value?": a hard-coded `24`, a channel of `1000`, a `10000`-byte buffer. The next person can't tell whether the number is a measured limit, a server contract or a guess, so it doesn't get changed when it should (or gets changed when it shouldn't). varlope points at time windows and queue capacities written as bare literals with no comment; whether they need a named `const` is the reviewer's call.
