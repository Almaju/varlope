`unsafe` code is only as sound as the reasoning behind it, so reviewers ask for a `// SAFETY:` comment on every block; writing one is how a wrong `transmute` in nimbus test helpers was caught. In NSS code, a manual free after a `?` leaks when the function exits early (#6997, #7015: found by LeakSanitizer in Firefox), and PKCS#11 constants declared `u64` instead of `CK_ULONG` broke the Windows build (#6876).
