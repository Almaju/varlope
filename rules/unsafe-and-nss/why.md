`unsafe` code is only as sound as the reasoning behind it, so reviewers ask for a `// SAFETY:` comment on blocks that touch raw memory; when they did in nimbus test helpers, one unexplained `transmute` turned out to be wrong. In NSS code, a manual free after a `?` leaks when the function returns early (#6997, #7015; LeakSanitizer caught one in Firefox), and PKCS#11 constants declared `u64` instead of `CK_ULONG` broke the Windows build (#6876).
