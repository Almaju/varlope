A panic in Rust code that runs on a value from Kotlin, Swift or JS takes the whole host app down with it, where an error would have been a catchable exception. #6967 fixed exactly this: webext-storage's `JsonValue` `try_lift` called `serde_json::from_str(..).unwrap()`, so invalid JSON from an extension crashed Firefox; constructors that return `Self` instead of `ApiResult<Self>` have the same problem with a bad path or config.
