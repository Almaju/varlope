Existing databases only change through `upgrade_from`: edit `CREATE TABLE`/`CREATE INDEX` without bumping `VERSION` and adding a step, and on-device databases never get the change, so queries fail or quietly run without the new index. Reviewers have blocked Suggest PRs for this again and again ("You'll need to bump the schema `VERSION` const and add a migration step to `upgrade_from()`"), and a `MigratedDatabaseFile` upgrade test catches a step that drifts from the fresh schema.
