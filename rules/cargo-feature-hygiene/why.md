Feature-gated code is only compiled when someone builds that combination, and Nimbus' `stateful` split kept breaking there: code calling an optional dependency outside its feature, gated variants leaking into the non-stateful build. A `#[cfg(feature = "…")]` naming a feature the crate doesn't declare compiles the code out silently, and `#[cfg]`s scattered over parameters and statements are hard to check by eye; reviewers ask for one attribute on the whole fn or module (e.g. under `stateful/`).
