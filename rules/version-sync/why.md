The Rust, Kotlin and Swift sides of Glean ship together, so `glean-sym` in Cargo.lock, `glean` in gradle/libs.versions.toml and `glean-swift` in Package.resolved must move in one PR; a bump that updated only some of them left the platforms on different Glean versions. The same goes for a second UniFFI version in Cargo.lock, and for the Android SDK and NDK versions that build.gradle, settings.gradle, the CI Docker image and docs/building.md each repeat.
