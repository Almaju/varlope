`map_err(|e| Error::X(e.to_string()))` throws away the source's type, so callers can no longer match on it and error reports lose the cause chain. Reviewers ask for a variant that holds the typed source with `#[from]`, so `?` converts it (#6454, #6818), and for a generic `Database` variant instead of putting every SQLite error under `OpenDatabase` (#7001).
